Итоговый проект по модулю "Разработка многостраничного сайта"

 Описание проекта
Данный проект представляет собой современный киносайт-каталог. На сайте реализован удобный интерфейс для просмотра популярных фильмов с адаптивной версткой.

 Использованные технологии
  HTML: Семантическая разметка (header, main, footer, section).
  CSS: Сетка Grid для каталога, Flexbox для навигации, адаптивный дизайн.
  JavaScript: Реализована смена тем оформления (светлая/темная).
     Динамическое добавление карточек фильмов по кнопке "Показать еще".
     Валидация формы обратной связи с выводом данных в консоль.
